# Sarath Preetham — Portfolio

## Quick setup
1. Open `index.html` in a browser to preview the portfolio.
2. Replace the placeholder email, GitHub and LinkedIn URLs in `index.html`.
3. Put your actual resume PDF in this folder and name it `resume.pdf`.
4. Replace the demo project links with your real GitHub repositories.
5. Update project descriptions after you finish each project.

## Publish with GitHub Pages
1. Create a GitHub repository named `yourusername.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `resume.pdf`.
3. In GitHub: Settings → Pages → Deploy from branch → main → root.
4. Your portfolio will be available at `https://yourusername.github.io/`.
